快速开始

  1. 安装 TeX Live（或 MacTeX / MiKTeX），中文支持需要 XeLaTeX。
  2. 克隆仓库 git clone https://github.com/ShinoharaHaruna/SDU-Beamer-Theme.git，或在 Releases 页下载起步包 zip。
  3. 运行 latexmk 生成 slide.pdf，然后改 slide.tex 写自己的内容。

常见问题

毕业答辩可以用这个模板吗？

可以。这是山东大学风格的非官方 Beamer 主题，大量学术报告与答辩场景在用。注意确认所在学院是否要求 pptx 格式——Beamer 输出 PDF，如需 pptx 可用 pdf2pptx 等工具转换。

Overleaf 免费版能编译吗？

完整版超出免费版编译时限。仓库自带 pack_overleaf.sh，执行 ./pack_overleaf.sh --no-bib 生成精简包，已验证可在免费版编译。

v1.x 和 v2.x 该选哪个？

求稳定、要参加正式答辩选 v1.x；喜欢现代设计风格、愿意尝鲜选 v2.x 公测版。两条线都会持续维护。

需要安装什么字体？

v1.x 起步包已附带所需的 LXGW WenKai 与 Sarasa Mono SC 正体字重，Times New Roman / Arial 使用系统自带即可。v2.x 使用 Noto Sans CJK 与 Fira 系列，多数 TeX Live 安装自带。

bibtex 还是 biber？

本项目按 biber 配置参考文献，直接运行 latexmk 会自动处理，不建议改用 bibtex。

English

SDU-Beamer-Theme is an unofficial LaTeX Beamer theme for Shandong University (SDU), built for academic talks, thesis defenses, and group-meeting presentations. Two product lines are maintained in parallel: the v1.x series (XeLaTeX, classic layout) and the v2.x series (LuaLaTeX, Moloch-style modern redesign, currently in beta). Both ship with one-command latexmk builds, GitHub Actions PDF builds, and a script that produces an Overleaf-free-plan-compatible package. See the GitHub repository for documentation and downloads.
